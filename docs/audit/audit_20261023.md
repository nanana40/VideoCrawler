- **文件/证据**：`.git/config:12` = `url = https://ghp_SP****（已脱敏，待轮换）@github.com/nanana40/VideoCrawler.git`（fetch/push 同址，主线程独立读取确认）。
- **影响**：PAT 明文存于仓库配置，仓库目录被同步/备份即泄露；修改记录确认其已出现在终端日志。

### AUDIT-0090【中】Web API key 无持久化，重启即更换
- **文件/证据**：`gui/web_host.py:41-46` `DEFAULT_API_KEY = _resolve_api_key()` 模块加载时 `token_urlsafe(24)` 随机生成，`:206` `os.environ.setdefault("VC_WEB_API_KEY", self.api_key)` 注入 env；`web/main.py:45` `API_KEY = os.environ.get("VC_WEB_API_KEY") or secrets.token_urlsafe(16)`。单次运行内两处 key 一致（setdefault 保证，已核实），但**不落盘**——每次重启 GUI 重新随机；对比 mqtt_bridge 的 token 持久化于 `data/mqtt_device.json`，web key 无对应持久文件。
- **影响**：旧的手机端 `?key=xxx` 书签、MQTT 二维码在 GUI 重启后全部失效，用户需每次从日志重新拷贝 key（用随机 key 替换弱硬编码后的可用性回退）。
- **一句话建议**：首次生成后持久化到 `data/web_api_key`（与 mqtt_device.json 同模式），或文档明确要求用户 `set VC_WEB_API_KEY` 固定。
- 附带次要项（并入本条）：web_host.py:42 日志明文打印完整 key（低，本地单用户可接受）；standalone 运行时 web/main 自生成 16 位 key 与内嵌 24 位不一致（次要）。
