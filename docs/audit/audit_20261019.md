## 三、本次新发现（AUDIT-0077～0086）

### AUDIT-0077（中）永久下载错误被当瞬时错误重试，白烧 yt-dlp 并放大限流
- 涉及文件：`core/download.py:35`（`class PermanentDownloadError`）、`:584`（`except PermanentDownloadError`）、`:865-883`（`_abort_incomplete`）
- 问题：`PermanentDownloadError` 专为"地区锁/版权/不可用不重试"而设，重试循环 `:584` 也专门捕获它直接返回；但全仓 Grep 确认它**只被定义和捕获、从未被 raise**。流闸门失败（`_abort_incomplete` 注释自承"多为视频流被地区/年龄限制阻断、cookies 过期"）实际抛的是 `RuntimeError`（:870），被 :593 通用 `except Exception` 捕获后按指数退避重试 3 次。
- 影响：永久不可用的视频也白跑 3 轮 yt-dlp，加重 YouTube bot 检测与限流，而本可一次返回。
- 建议：`_abort_incomplete` 对"无视频流/缺音频合并不完整"等永久情形改抛 `PermanentDownloadError`；仅"未产出文件"等瞬时情形保留 RuntimeError 重试。

### AUDIT-0078（中）image_provider.call_pollinations 名不副实：文生图伪装成图生图，输出错误封面
- 涉及文件：`core/image_provider.py:307-357`（`POLL_PROMPT` :310-314、`call_pollinations` :317-357）、链 :366-370
- 问题：`call_pollinations(image_path)` 在"图生图翻译"链（`PROVIDER_CHAIN` 第 3 位，:369）中，入参为任意封面；但代码注释（:307）自承 pollinations 的 `/prompt` **只做 T2I（文生图）**。URL 路径固定拼接硬编码 `POLL_PROMPT`（一段"Kurzgesagt 大脑缩略图、把德文字幕换成中文"的固定 prompt，:310-314），传入图片仅被压成 384px 塞进 `image=` 参数（该 T2I 端点不把它当参考图）。
- 影响：无论传入什么封面，该分支都会输出与原图无关的"大脑"固定封面——是"看起来会工作、实际产出错误图片"的陷阱分支。
- 建议：删除 pollinations 分支，或改接真正的图生图端点；当前应避免它静默产出错误封面。

### AUDIT-0079（中）一键启动脚本悬空引用已删除的 watchdog/cloudflared，独立部署路径已坏
- 涉及文件：`start_all.bat`（仍 `python -m web.watchdog`）、`start_tunnel.bat`（调已删的 `web/cloudflared.exe`，健康检查硬编码 `?key=VideoCrawler2026`）、`web/wake.html`（仍 fetch 已不存在的 :8001 watchdog 端口）
- 问题：`web/watchdog.py` 已删除，`start_all.bat` 却仍 `python -m web.watchdog`（实测文件不存在）；`start_tunnel.bat` 引用的 `cloudflared.exe` 也已移除。
- 影响：用户双击 `start_all.bat` 立即报 `No module named web.watchdog`；三个文件成为误导性死入口。
- 建议：统一为 GUI 内嵌模式（`start_gui.bat` 走 main_gui.py），删除或改写这三个文件。

### AUDIT-0080（中）新增 _test_mqtt.py 硬编码弱密钥并散落根目录

### AUDIT-0081（低）image_provider._download_image 递归下载无深度限制
