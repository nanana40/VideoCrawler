## 二、新发现问题

### AUDIT-0092【中】build_gui.spec 未覆盖 web/，且 excludes 明确排除其运行栈
- **文件/证据**：
  - `build_gui.spec:20` hiddenimports 仅 `["core","utils","gui"]`、`:49` datas 仅 `["core","utils","gui","resources"]`——均无 `web/`；
  - `build_gui.spec:92-95` excludes 明确排除 `"uvicorn", "fastapi", "starlette"`（Web 服务运行栈）；
  - 引用链全为函数内延迟导入：`gui/web_host.py:222` `from web.main import app`、`:350` `from web.mqtt_bridge import MqttBridge`、`gui/main_window.py:323,355`；
  - `web/static/`（index.html/mobile.html）不在 datas。
- **影响**：GUI 打包（frozen 模式）后启用 Web 远程控制/MQTT 桥接时，web/main.py、web/static/*.html、fastapi/uvicorn 均缺失，远程功能运行时崩溃。与 0076（app/ 未覆盖）不同：app/ 经 `main_gui.py:65 → utils.app_initializer:8 → app.bootstrap` 顶层 import 链可被 PyInstaller modulegraph 追踪，而 web/ 全为函数内延迟导入且被 excludes 主动排除。
- **一句话建议**：在 spec 的 hiddenimports/datas 列表加 `"web"`（含 `web/static`），并从 excludes 移除 uvicorn/fastapi/starlette（或按 0057 已删 watchdog 后的部署形态重新评估是否需要排除）。

### AUDIT-0093【中】task_scheduler.py 顶层 import psutil 未声明依赖
- **文件/证据**：`core/task_scheduler.py:20` `import psutil`（模块顶层，非惰性）；`requirements-runtime.txt` 全文无 psutil（grep 0 命中），psutil 也非 APScheduler/PySide6 传递依赖。
- **影响**：干净环境按 requirements-runtime.txt 安装后，首次 `import core.task_scheduler` 即 `ModuleNotFoundError: No module named 'psutil'`，调度器无法启动（开发机已装故未暴露）。
- **一句话建议**：在 requirements-runtime.txt「调度与监控」段补 `psutil>=5.9.0`。

### AUDIT-0094【低】httpx 已用未声明（顶层一处、惰性两处）
- **文件/证据**：
  - `core/publish/xhs_api_client.py:34` `import httpx`（**模块顶层**）——0063 的 try/except 懒加载（:38-47）只保护 xhs_cli，未覆盖 httpx；若 httpx 未装，import 本模块即崩，懒加载保护被部分架空；
  - `core/gemini_engine.py:326,:392` `import httpx`（函数内惰性，调用 AI 引擎才触发）；
  - `requirements-runtime.txt` 无 httpx；`build_gui.spec:30-40` hiddenimports 亦无 httpx。
- **影响**：干净环境未装 httpx 时，发布模块导入失败（顶层）或 AI 引擎调用时失败（惰性）。
- **一句话建议**：requirements-runtime.txt 补 `httpx>=0.27.0`（或明确经 xhs_cli 传递引入并在打包清单补全）。

### AUDIT-0095【低】README 与代码脱节（入口/目录树/打包/版本）
- **文件/证据**：
  - `README.md:271` 写 `venv\Scripts\python.exe main.py` 为入口，:77 目录树列 `main.py 程序唯一统一入口`——实际 GUI 入口是 `main_gui.py`（start_gui.bat 指向 `D:\python\python.exe main_gui.py`），README 通篇未提 main_gui.py；
  - README 无 web/ FastAPI 服务、端口 8000、`VC_WEB_API_KEY`/`VC_WEB_HOST`、MQTT bridge 任何说明（用户按文档不知远程功能存在、不知 key 从日志获取）；
  - :35-85 目录树缺 web/、gui/pages/、core/pipeline.py 等；
  - :29 技术栈写 PyInstaller、:78 写 `build.py Nuitka 打包脚本`——自相矛盾；
  - :20 写 Python 3.11+，实际运行 3.14。
- **影响**：新用户按 README 无法启动 GUI、不了解远程功能；文档误导（打包工具冲突）。
- **一句话建议**：README 补 main_gui.py 入口与 web 远程章节（含 key 获取方式），修正目录树与打包工具描述（归属文档维护，可并入路线图阶段 4 收尾）。
